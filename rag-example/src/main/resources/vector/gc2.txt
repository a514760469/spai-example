判断垃圾的方法有哪些？
Java 里判断对象是不是垃圾，主要有两类思路：引用计数法和可达性分析。Java 实际采用的是可达性分析，也叫根搜索算法。

引用计数法：给对象加一个引用计数器，被引用一次加一，引用失效减一，减到零就认为可回收。优点是实现简单、判断实时。缺点是无法解决循环引用，比如两个对象互相引用，外部已经不可达，但计数器都不为零，导致无法回收。所以 Java 没有采用它。

可达性分析：从一组 GC Roots 出发，沿着引用链搜索，能到达的对象是存活对象，不能到达的就是可回收对象。GC Roots 包括虚拟机栈中局部变量表引用的对象、本地方法栈中 JNI 引用的对象、方法区中静态变量引用的对象、方法区中常量引用的对象、活动线程、类加载器、同步锁持有的对象、JVM 内部引用等。

对象被判定不可达后，不一定马上回收。如果对象覆盖了 finalize 方法且还没执行过，JVM 可能把它放入 F-Queue，由 Finalizer 线程执行 finalize。如果对象在 finalize 中重新和引用链关联，就能复活；否则第二次标记后回收。

另外，Java 的引用类型也会影响对象回收时机。强引用只要存在就不会回收；软引用在内存不足时回收；弱引用在下一次 GC 时回收；虚引用不能用来获取对象，只用于回收通知。

三色标记法是可达性分析在并发场景下的具体标记实现，比如 CMS、G1 会用它来处理并发标记，但它不是独立于可达性分析的另一套判断垃圾的方法。

总结：判断垃圾的基本方法有引用计数法和可达性分析。Java 使用可达性分析，并通过 GC Roots、引用类型和 finalize 机制等共同决定对象是否回收。
